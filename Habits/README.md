###### Installation and Run Instructions: User Setup & Operation Manual
1. Open Windows PowerShell or a Command Prompt
2. Type or drag and drop your downloaded file to the Shell (make sure to extract the whole file from the zip folder first)
   - e.g. Type: "C:\Users\your-own-username\Downloads\Habit_Tracking_App-main\Habits"
   - e.g. "C:\Users\ilkay\Downloads\Habit_Tracking_App-main\Habits"
4. Hit Enter
5. Next, type the following: python main.py
6. Hit Enter
